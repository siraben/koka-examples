# koka-examples

Reference applications for the Milestone-4 engineering program.

| project         | what it is                                                    |
| --------------- | ------------------------------------------------------------- |
| `notes-service` | an HTTP/JSON API over SQLite: the program's one vertical slice |

Each project has its own `koka.toml` and depends on the packages in the sibling
`koka-packages` checkout by path. See the project's README for how to build,
test and run it.
